# Pixiv 图片批量下载器

一个简单易用的 **Pixiv** 批量图片下载工具，支持多任务并发、实时进度显示、断点续传等功能。

## ✨ 功能特点

- **多任务并发**：支持同时下载多个作品（默认3个任务同时进行）
- **实时进度**：每个任务的下载进度实时可见，包含速度、完成数量等详细信息
- **断点续传**：下载中断后可继续，已下载的图片不会重复下载
- **暂停/停止**：随时可以暂停或停止正在下载的任务
- **Cookie 认证**：通过导入浏览器 Cookie 实现登录认证
- **批量管理**：支持添加多个任务，统一管理
- **智能解析**：自动识别 Pixiv URL 格式，提取关键参数

## 📦 安装与运行

### 环境要求

- Python 3.8 或更高版本
- Windows 操作系统（推荐）
- 可以访问 Pixiv 网络（需要科学上网）

## 🚀 使用指南

### 第一步：登录认证

由于 Pixiv 需要登录才能查看/下载部分图片，建议先进行登录：

1. 点击工具栏的 **"未登录"** 状态标签，或菜单 → 工具 → 登录
2. 推荐使用 **Cookie 导入**方式：
   - 在浏览器中登录 pixiv.net
   - 按 F12 打开开发者工具
   - 切换到 Network 标签，刷新页面
   - 点击任意请求，找到 Request Headers 中的 Cookie 字段
   - 复制完整的 Cookie 值粘贴到应用中
3. 点击 **"导入 Cookie 并登录"**

### 第二步：添加下载任务

1. 点击 **"+ 新建任务"** 按钮
2. 填写必要信息：
   - **作品链接**：Pixiv 作品页面 URL
     ```
     示例: https://www.pixiv.net/artworks/137875526
     ```
   - **第一张图片地址**：该作品的第一张图片下载链接
     ```
     示例: https://i.pximg.net/img-master/img/2025/11/25/14/21/03/137875526-xxx_p0_master1200.jpg
     ```
     > 如何获取：在作品页面右键点击第一张图片 → 复制图片地址
   
   - **保存目录**：选择图片要保存到的文件夹路径

3. （可选）调整高级选项：
   - 最大页数、重试次数、超时时间、请求间隔等

4. 点击 **"确定"** 添加任务

### 第三步：开始下载

- 点击 **"全部开始"** 按钮即可开始所有等待中的任务
- 可在任务列表中查看每个任务的实时进度
- 支持对单个任务进行暂停、停止操作

### 第四步：查看结果

- 下载完成的图片会保存在指定的目录中
- 文件命名格式：`{作品ID}_p{页码}.jpg`
- 例如：`137875526_p0.jpg`, `137875526_p1.jpg`, ...

## 🎯 核心功能详解

### 断点续传

如果下载过程中中断（关闭程序、网络问题等）：

1. 重新打开程序
2. 再次添加相同的任务（相同的作品链接和图片地址）
3. 程序会自动检测已存在的文件并跳过
4. 从上次中断的位置继续下载

### 多任务并发

- 默认支持 **3 个任务** 同时下载
- 可在设置中调整并发数量（开发中）
- 任务队列会自动调度，完成的任务会自动启动下一个

### 进度监控

每个任务显示以下信息：
- 当前下载进度（第几张 / 总共预估张数）
- 当前进度条可视化
- 实时下载速度 (MB/s 或 KB/s)
- 成功/失败计数

### 错误处理

- 自动重试机制（默认3次）
- 超时处理（默认30秒）
- 404 自动停止（表示图片全部下载完毕）
- 详细的错误日志记录

## ⚠️ 注意事项

### 关于访问 Pixiv

- **需要科学上网**：在中国大陆无法直接访问 Pixiv，请确保已经配置好代理
- **代理设置**：程序会使用系统代理，也可以在登录时配置专用代理

### 关于 Cookie 有效期

- Cookie 通常有效期为 **30 天**
- 如果发现无法下载（403 错误），可能需要重新获取 Cookie
- 程序会在 Cookie 接近过期时提醒您

### 关于下载限制

- Pixiv 对请求频率有限制，程序已内置合理间隔（默认1秒）
- 不要同时下载过多任务，以免被限流或封禁 IP
- 建议单次下载任务不超过 10 个

### 目录名处理

程序会自动清理目录名中的非法字符：
- 移除：`/ \ * ? " < > | : · 。.` 等
- 截断超过 200 字符的长名称
- 确保生成的目录名在 Windows 下合法

## 🔧 常见问题

### Q: 提示 "403 Forbidden" 怎么办？

A: 这通常意味着：
1. Cookie 已失效或未登录 → 重新导入 Cookie
2. 该图片需要登录才能查看 → 确认账号有权限
3. 被限流了 → 降低并发数，增加请求间隔

### Q: 下载速度很慢？

A: 可能的原因：
1. 网络本身慢（科学上网的带宽限制）
2. 单张图片较大
3. 设置的间隔时间太长
4. 可以适当调大并发数

### Q: 如何批量导入多个任务？

A: 目前可以通过以下方式：
1. 手动逐个添加（推荐少量任务时）
2. 使用"导入任务列表"功能（JSON 格式）
3. 后续版本将支持从文本文件批量导入

### Q: 程序崩溃或无响应？

A: 尝试以下步骤：
1. 检查 Python 和依赖是否正确安装
2. 查看命令行输出的错误信息
3. 重启程序
4. 如果持续出现问题，可以提交 Issue
